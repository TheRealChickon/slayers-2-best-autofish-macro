# Window design

The window uses a neutral charcoal background (`#18191c`), one raised surface (`#24262b`), soft white text (`#e9eaec`), and secondary gray text (`#a0a4ad`). Item artwork carries most of the color. Green indicates activity and red indicates errors; navigation does not introduce another saturated accent.

One header, one summary row, and one tab bar establish the hierarchy. The inventory gets the available width. Item quantities use quiet dark badges. The footer presents either Pause or Continue as the primary action. Hover fades, a moving tab indicator, and short page transitions provide feedback; Reduce motion disables them.

The terminal retains its existing appearance and navigation.

References used:

- [Google's Material dark-theme codelab](https://codelabs.developers.google.com/codelabs/design-material-darktheme): restrained color and surfaces with different lightness.
- [Nielsen Norman Group: five visual-design principles](https://www.nngroup.com/articles/principles-visual-design/): hierarchy, scale, contrast, balance, and proximity.

The design borrows the game's inventory organization and uses locally captured item thumbnails. It does not reproduce the entire game interface.
